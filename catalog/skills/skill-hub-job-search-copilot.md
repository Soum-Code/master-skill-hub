# job-search-copilot

> End-to-end job search help for tech, AI/ML and data roles. Use for resume or CV tailoring, job description analysis, cover letters, referral and recruiter messages, application tracking, "help me apply to this role", fit-gap analysis, and comparing or negotiating offers. Maps each requirement in a job description to real evidence from the user's background, rewrites bullets with measurable results, and never invents experience, titles, dates or numbers.
